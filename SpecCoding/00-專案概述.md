# 專案概述

## 專案名稱

GoJapan - 日本旅遊行程管理系統

## 專案版本

**當前版本**: 2.0.0

## 專案描述

GoJapan 是一個功能完整的旅遊行程管理系統，專為日本旅遊設計，支援行程規劃、支出分帳、地圖定位、天氣查詢、匯率換算、翻譯功能等。採用 Vue 3 Composition API 架構，提供本地儲存與 Firebase 雲端同步功能，支援多人協作與即時同步。

## 專案目標

1. **行程規劃**: 提供直觀的行程規劃介面，支援多天行程、地點標記、航班資訊
2. **支出管理**: 支援個人記帳與多人分帳，自動計算結算方案
3. **雲端協作**: 透過 Firebase 實現多人即時協作，支援邀請碼分享
4. **資訊整合**: 整合天氣、匯率、地圖、翻譯等實用功能
5. **離線可用**: 本地儲存優先，離線環境下仍可使用基本功能

## 目標使用者

-   個人旅遊規劃者
-   多人團體旅遊（朋友、家人）
-   需要協作規劃行程的使用者

## 核心價值

-   ✅ **本地優先**: 所有資料優先儲存在本地，確保隱私與離線可用
-   ✅ **雲端同步**: 可選的雲端同步功能，支援多人協作
-   ✅ **即時協作**: 支出資料支援即時同步，多人可同時編輯
-   ✅ **資料安全**: 本地資料不會因雲端問題而遺失
-   ✅ **易用性**: 直觀的介面設計，降低學習成本

## 技術特色

-   Vue 3 Composition API 架構
-   TypeScript 完整型別定義
-   Firebase Firestore 雲端資料庫
-   Tailwind CSS 響應式設計
-   模組化 Composables 設計
