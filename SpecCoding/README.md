## 使用方式

### 開發人員
- 閱讀 `01-需求規格.md` 了解專案需求
- 閱讀 `02-功能規格.md` 了解功能細節
- 閱讀 `03-技術架構.md` 了解技術設計
- 閱讀 `04-資料結構.md` 了解資料格式
- 閱讀 `05-API規格.md` 了解 API 使用方式

### 測試人員
- 閱讀 `07-測試規格.md` 了解測試案例
- 根據測試案例執行測試
- 記錄測試結果

### 部署人員
- 閱讀 `08-部署規格.md` 了解部署流程
- 根據部署規格執行部署
- 檢查部署結果

### 專案管理
- 閱讀 `06-開發歷程.md` 了解專案歷史
- 追蹤版本更新
- 規劃未來功能
